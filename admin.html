To activate AdSense:

1. Deploy site on Vercel with verityadaily.com
2. Publish 15-20 original quality posts (manual, not AI-spam)
3. Apply at adsense.google.com
4. Add AdSense code snippet to <head> of all pages
5. Replace ad-zone placeholders with AdSense auto-ad code
6. Wait 1-14 days for approval
7. Start earning 💰
